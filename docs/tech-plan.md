---

## 一、总体定位

本作品构建一个**面向通用科研领域**的多智能体 AI Scientist，接收自然语言科研问题（及可选 PDF/CSV/图表等证据），通过「问题理解 → 证据组织 → 知识缺口识别 → 候选假设生成 → 比较筛选 → 研究计划形成 → 反馈修订」的闭环，输出 10 字段《科学假设与研究计划》。系统不写死任一学科，通过四库 RAG 与可插拔知识库/提示词即可迁移到材料、生物、农业、社会科学等方向。

## 二、系统架构（四层）

见 [architecture.md](architecture.md)：前端交互层 / 业务后端层 / 多智能体服务层 / 数据引擎层 四层架构。

## 三、八 Agent 管线

见 [agents.md](agents.md)：① 问题理解 → ②∥③ 文献检索与知识发现（并行、自足 RAG）→ ④ 假设生成 → [人在回路暂停] → ⑤ 评估（含幻觉检测）→ ⑥ 实验设计 → ⑦ 思辨辩论 → ⑧ 报告生成 → 输出 10 字段。

## 四、关键技术点

| 关键点 | 实现 |
|---|---|
| 基座模型 | Qwen-Max / Qwen-Plus / Qwen-Turbo（阿里云百炼平台调用，OpenAI 兼容 API） |
| 编排 | LangChain4j：@Tool / @AiService / DAG State 流转 |
| RAG | 四库（论文/方法/数据集/证据）+ 混合检索（向量 + BM25） |
| 幻觉检测 | 反向比对真实文献（评估 Agent），虚构引用打回重做（DOI/PMID/URL 白名单） |
| 人在回路 | 前端 Vue Flow 交互 + 管线暂停点，人类导师审阅介入 |
| 微调（可选） | 百炼平台 SFT（Qwen-Turbo + LoRA）或检索模型微调 |

## 五、代表案例（SSD 存储）

系统在「深度学习 × SSD 存储」上完成一个可运行、可展示、可复现的典型案例：基于真实存储论文与 I/O 数据，识别现有 LSTM 温度预测、文件感知垃圾回收等方法的边界，形成「文件语义 + 时空负载建模 + 不确定性门控」的候选研究假设（FSTU-GC），并给出基线、指标、数据采集方案与可复现实验步骤。该案例用于演示系统在通用领域上的完整闭环能力；系统本身不限定于存储领域。

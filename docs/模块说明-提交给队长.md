# 丁贾峻模块说明

## 模块名称

AI 底层基建与运维模块。

## 已提供能力

1. 基于阿里云百炼 OpenAI 兼容接口的 Qwen-Plus 调用服务。
2. 基于 DashScope Embedding 模型的文本向量化服务。
3. 基于 Chroma 的知识文本入库和相似度检索服务。
4. 不含 API Key 与原始提示词的调用审计日志。
5. Docker Compose 部署文件、Postman 测试集和 PowerShell 一键验收脚本。

## 对其他成员的接口

| 接口 | 用途 | 调用方 |
| --- | --- | --- |
| `POST /api/llm/chat` | 调用 Qwen 生成回答 | Agent 编排层 |
| `POST /api/vectors/documents` | 写入清洗后的知识文本与元数据 | 数据引擎层 |
| `POST /api/vectors/search` | 按语义检索 Top-K 相关知识 | 文献检索、知识发现、假设生成、评估 Agent |
| `GET /api/llm/logs` | 获取模型调用状态和耗时 | 运维、技术文档 |

## 待联调输入

数据引擎层入库文本应包含正文片段和至少以下元数据：`source`、`title`、`year`、`url` 或 `doi`。引用真实性由上层评估 Agent 根据返回的来源元数据进行核验。

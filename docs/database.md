# 数据库设计（Database Design）

> 更新时间：2026-08-05（初版）
> ⚠️ **占位文档**：表结构与字段定义由后端组（任怡名）设计时确定，本文档仅固化已知需求边界，避免过早固化细节。

## 1. 需求边界（已确认）

| 模块 | 已知需求 | 状态 |
|---|---|---|
| 用户管理 | 用户信息（赛期可简化，支持匿名/单用户模式） | 待设计 |
| 任务管理 | 科研任务记录：任务状态、参数、创建时间 | 待设计 |
| SSE/管线状态 | 任务与管线 State 关联（断点恢复用） | 待设计 |
| 历史报告 | 生成的《科学假设与研究计划》存档（10 字段 JSON） | 待设计 |
| 文件管理 | 上传的 PDF 文献 / CSV 数据元信息 | 待设计 |
| 日志 | API 调用日志、百炼调用日志（赛题要求留存凭证） | 待设计 |

## 2. 技术选型

- MySQL 8.0（开发）/ PostgreSQL（可选）
- 字符集：utf8mb4（支持中文）
- ORM：由后端组选定（Spring Data JPA / MyBatis-Plus）

## 3. 预留表（命名建议，具体字段由团队确定）

```
user          -- 用户
task          -- 科研任务
task_file     -- 任务关联的上传文件
task_state    -- 任务/管线状态（断点恢复）
report        -- 生成的研究计划（10 字段 JSON）
llm_call_log  -- 百炼 API 调用日志（含凭证截图关联）
```

## 4. 向量数据库（另见 rag.md）

- 向量数据（论文/方法/数据/证据四库）存放于 Chroma / Milvus
- collection/schema 字段定义由数据引擎组 + 后端组设计时确定
- 约定：**每条向量必须携带来源标识（DOI/PMID/URL）**，支撑评估 Agent 幻觉检测

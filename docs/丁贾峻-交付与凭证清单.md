# 丁贾峻交付与凭证清单

## 已准备的代码交付

| 交付项 | 位置 | 验收方式 |
| --- | --- | --- |
| 百炼 Qwen 调用接口 | `POST /api/llm/chat` | 返回模型回答 |
| Embedding 调用 | `DashScopeService.embed` | 返回非空向量 |
| Chroma 文本入库 | `POST /api/vectors/documents` | 返回文档 ID |
| Chroma 相似检索 | `POST /api/vectors/search` | 返回相关文档和距离 |
| 非敏感调用日志 | `GET /api/llm/logs` | 记录模型、状态、耗时，不含密钥与提示词 |

当前演示默认使用本地内存向量检索，不依赖 Docker；该模式重启后数据会清空。Docker 网络恢复后设置 `CHROMA_ENABLED=true` 即可切换到 Chroma 持久化服务。

## 技术方案可直接使用的说明

系统经阿里云百炼 OpenAI 兼容接口调用 Qwen-Plus，承担科研问题理解、文本摘要和推理等生成任务；Embedding 模型将知识条目向量化。向量及元数据写入 Chroma，由检索接口向文献检索、知识发现、假设生成和评估 Agent 提供 Top-K 证据片段。调用日志保留时间、模型、状态码和耗时，便于复现实验和排查故障，同时避免记录 API Key 与原始研究输入。

## 凭证截图顺序

1. 百炼控制台：显示已开通模型服务和可用模型名称。截图不得展示完整 API Key。
2. 终端：`java -version`、`mvn -version`，证明 Java 17 与构建环境。
3. 终端：`docker compose up -d` 成功，随后显示 Chroma 容器运行状态。
4. Postman：`Health` 返回 `UP`。
5. Postman：`Qwen Chat` 返回内容，展示请求 URL、状态码和模型输出片段。
6. Postman：先执行 `Add Knowledge`，再执行 `Search Knowledge`，展示检索结果中的文档和距离。
7. Postman：`API Logs` 返回模型、成功状态和耗时。

截图文件建议命名为 `01-百炼模型开通.png` 至 `07-调用日志.png`，并单独保存到技术文档素材目录。不要在截图、日志或 Git 中保存 API Key。
